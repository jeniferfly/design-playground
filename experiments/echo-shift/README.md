# 🎮 ECHO / SHIFT

**An AI-assisted exploration of cinematic game design, sound-driven interaction, and immersive visual storytelling.**

ECHO / SHIFT is an independent creative experiment exploring how sound, environmental transformation, and cinematic storytelling can come together in an original interactive experience.

Drawing on my professional background at PlayStation and my appreciation for the cinematic storytelling of *Uncharted 4: A Thief's End*, I wanted to investigate how atmosphere, camera composition, audio, and player interaction could create a cohesive, emotionally engaging experience.

The project combines visual design, interaction design, game mechanics, and AI-assisted creative development.

### Creative Objectives

- Explore cinematic environmental storytelling and atmospheric world-building.
- Develop original sound-driven puzzle mechanics.
- Combine visual craftsmanship with accessible player interactions.
- Experiment with AI-assisted creative exploration, prototyping, and development.
- Document the design decisions, technical challenges, and iterative process.

### Project Status

**Phase 2 — Visual Golden Standard / Playable Prototype Development**

The current phase focuses on establishing the approved in-game visual direction before extending the playable experience.

### Development Approach

Human-led creative direction, supported by AI-assisted exploration and development, with deterministic gameplay mechanics and controlled procedural variation.

### What's Next

The planned release will include a browser-based playable experience, source code, documented creative and technical decisions, and a completed portfolio case study.
